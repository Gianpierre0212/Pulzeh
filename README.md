# PULZEH

Monitor de rendimiento del sistema para Windows.

## Descripción

PULZEH es una aplicación de escritorio desarrollada en Rust que muestra información real sobre el uso del procesador y la memoria RAM.

## Estado actual

Versión: 0.1.0

Funciones disponibles:

- Uso actual de CPU.
- Promedio reciente de CPU.
- Uso de memoria RAM.
- Porcentaje de memoria utilizada.
- Actualización periódica.
- Interfaz gráfica oscura.
- Datos obtenidos directamente del sistema.

## Tecnologías

- Rust
- egui
- eframe
- sysinfo
